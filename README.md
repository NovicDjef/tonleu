# Novic Tonleu — Portfolio

Portfolio de Novic Tonleu, développeur full stack web et mobile basé à Sept-Îles (Québec) : applications React Native, plateformes web Next.js et API Node.js.

## Lancer le projet

```bash
npm install
npm run dev
```

Pour une version de production :

```bash
npm run build
npx vite preview
```
